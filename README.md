# SafeGuardian

Interactive mobile UI prototype. Open `index.html` or serve this directory with a static web server.

Includes Web Cleanup, Spam Calls Filter, SMS Filter, WiFi Test, Vault and Me.

## Prototype limitations

Permissions, protection, network measurements and system settings are simulated. No actual calls, messages or Safari content are filtered. Vault passcodes and media are held in memory; this is not encrypted, durable storage. Do not enter real passwords or import private photos. Reloading resets state.

The `assets/icons` directory includes third-party icon licensing and source information.
