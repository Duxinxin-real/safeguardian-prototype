# Icon sources

UI symbols in index.html use SVG geometry downloaded from the official Lucide repository:
https://github.com/lucide-icons/lucide/tree/main/icons

Downloaded 2026-10-27. Original SVGs and the upstream LICENSE are stored here.
The interface inherits its colors and stroke widths from CSS.

Mappings: shield → shield-check; ban → ban; window → app-window;
eye → eye-off; gauge → gauge; lock → lock; person → user-round;
arrow → chevron-right; sliders → settings-2; photo → image;
calendar → calendar-days.
Vault empty albums: Photos → image; Videos → video (official Lucide SVG).
Privacy Tools: Spam Calls → phone; SMS Filter → message-square (official Lucide SVG).

These are similar library icons, not claimed to be the source of the generated design.
The large active and inactive shield illustrations still use the approved design images.
